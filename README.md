Brain Tumor Detection Using MRI Images

Tech Stack: Python, Scikit-learn, Streamlit

Developed a machine learning–based brain tumor detection system using a Random Forest classification model with image preprocessing techniques such as resizing and normalization. Evaluated model performance using accuracy score and confusion matrix to ensure reliable prediction results.

Built an end-to-end pipeline in Python for data preprocessing, model training, validation, and serialization. Designed an interactive Streamlit frontend that allows users to upload MRI images and receive real-time tumor prediction outputs through a simple and user-friendly interface.
