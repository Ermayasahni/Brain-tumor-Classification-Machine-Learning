# Brain-tumor-Classification-Machine-Learning
Brain Tumor Detection Using MRI Images | Python, Scikit-learn, Streamlit Developed a Random Forest–based classification model with image preprocessing (resizing, normalization) and performance validation using accuracy and confusion matrix. Deployed an end-to-end machine learning pipeline with Streamlit for real-time brain tumor prediction.
